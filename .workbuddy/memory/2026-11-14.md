## 阶段 P1 文档入库

- 真实语料：`data/raw/` 放汇川 CP 系列三份手册（CP320 变频器 56 页 / CP600 一体机 33 页 / CP650 一体机 74 页），均从 omkkyj.com 直链下载，不放任何示例文档。
- 实现 loader（PyMuPDF 文本层 + `find_tables` 校验版表格转 markdown + 低字符页转 OCR）、ocr（PaddleOCR 3.7.0，按行距聚段，段落均置信度 <0.6 打标）、chunker（字号众数定基准 + 编号正则层级栈，400–800 字，100 字句界重叠，表格原子）、pipeline（sha256 幂等 + 状态机 + 失败写 failed_reason 不中断）。
- 环境限制：本机无 Docker/PostgreSQL，全部验证走 `sqlite+pysqlite:///C:/Users/clm/AppData/Local/Temp/kb_p1.db`，解释器为 `C:\Users\clm\AppData\Local\Temp\kb-verify-venv\Scripts\python.exe`；pgvector 真实链路待用户 docker compose 验收。
- 基线结果：3 文件 / 163 页 / 6 OCR 页 / 207 块 / 0 失败；同一 DB 复跑 0 新增（幂等通过）。抽样明细见 `data/eval/p1_sample_blocks.md`。
- 已知缺陷（待修）：① CP600 章节标题位于页面 y=37.6（落在 8% 页眉带内）且与页眉文字相同，被当页眉删除，导致 2/3/4/5 章层级全挂在「1安全注意事项」下；② 奇偶页交替页眉（「前 言」「安全注意事项」各只出现 2 次）未达 ≥3 重复阈值，残留混入正文块；③ PDF 项目符号双重绘制产生「◆ ◆」纯符号行。
- 修复方向：页眉判定加字号豁免（显著大于正文字号的行不删）；重复阈值改 ≥2 且 ≥10% 页数；丢弃纯符号行并合并重复前导符号。

### 修复结果（run3 基线）

- `_drop_running_lines` 改为三规则：字号 ≥ 正文 +3pt 豁免（`RUNNING_SIZE_SLACK`）、重复 ≥3 次或（≥2 次且 ≤24 字）（`RUNNING_REPEAT_HARD/SOFT`）、页码正则先于字号豁免。
- `_scan_page` 新增 `_split_segments`：同一行 span 水平间距 > 36pt 即拆成独立行（`LINE_GAP_PT`）。这是页眉剔除不干净的真正根因——「附录A参数表 + 手册名」被拼成一串、每章都不同，重复计数被打散。
- 剥除前导项目符号（`_BULLET_CHARS`），整行皆符号则丢弃，消除 `◆ ◆`。
- 修复后：CP600 章节层级恢复正确（2产品信息 > 2.3基本技术规格、3安装、4接线、5显示说明与调试）；抽样中 ◆ 与手册名残留均为 0；块数 207 → 203（页眉行不再单独成块）；幂等复跑 0 新增；pytest 1 passed。
- 遗留噪声：图注与表题粘连（「…示意图表4-2 …」）、嵌套表格重复渲染、合并单元格串行、「危/险」竖排单字分裂——已写入 PROJECT_SPEC 风险。

## 阶段 P2 检索层

- 实现 `app/retrieval/`：vector（bge-small-zh-v1.5 单例 + pgvector `<=>` / SQLite 内存余弦）、bm25（jieba + rank_bm25，内存索引按块数自动失效重建）、hybrid（RRF k=60）、rerank（CrossEncoder 可开关）、`__init__.search()` 统一入口、`bench.py` 评测 CLI。
- 评测集 `data/eval/smoke_queries.jsonl` 10 条，金标按「文档 + 页码」标注，页码由入库块正文反查确定（非跑完结果后调整）。三份手册同源，文档级指标必然虚高，因此同时报页码级。
- 基线（默认 rerank 关）：页码级 Recall@5 = vector 0.900 / hybrid 1.000 / hybrid_rerank 1.000；耗时 77~102ms。开启重排后 2543ms（10 候选 / 256 token），首版 20 候选 / 512 token 时高达 9804ms。
- 关键结论：q07 是唯一向量失手题，金标在向量里排 #13、BM25 排 #1，融合后落到第 4 —— RRF 保住 K=5 命中但牺牲 Top1 精度。失分根因是**超长参数表块（1700+ 字）向量被平均化**，属切块问题，不是融合参数问题。
- 工程细节：`chunks.embedding` 用 `Vector(512).with_variant(JSON(), "sqlite")`，本机无 Docker 也能跑同一套 ORM；`Chunk.document` 加 `lazy="joined"` 供会话外取引用；Dockerfile 补 `libgomp1`（torch 依赖），compose 加 `modelcache` 卷与 HF_ENDPOINT。
- 验证：`pytest` 11 passed；`python -m app.retrieval.bench --verbose --trace q07` 输出见 `data/eval/p2_bench_report.md`。pgvector 真实链路仍待用户 compose 验收。
